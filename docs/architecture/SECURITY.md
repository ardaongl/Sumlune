# Security Architecture — PLAN-07 / Accepted (ADR-0016)

Kapsam Accepted (ADR-0003, 0005, 0014, 0015); teknik tasarım ADR-0016 ile Accepted; crypto/SDK/cihaz doğrulaması şartlı. Hedef: güvenli yerel finans, ücretsiz temel kullanım, taşınabilir yedek. Root/jailbreak, ele geçirilmiş veya açık cihaz, ekran fotoğrafı ve OS/launcher cache için mutlak güvenlik iddiası yok. Tehdit: cihaz kaybı, backup ifşası, yanlış restore, key kaybı, raw banka içeriği, widget/deep link, bulut hesap ele geçirme.

## 1. Yerel veri ve anahtar
- SQLCipher tek finansal SQLite (ADR-0009 uyumluluk koşullu); CSPRNG 256-bit random DB key, Expo SecureStore/OS Keystore-Keychain app-private saklama. Key Git/log/SQLite/async storage/widget/cloud yok. Android uninstall ve iOS keychain persistence farkı test. Key bulunamazken mevcut DB varsa yeni key ile üzerine yazma/reset yok; recovery ekranı. İlk kurulum/restore yeni key; DB dosyası ve key OS auto backup dışında (platform config doğrula). WAL/SHM, temp, migration ve export path plaintext leakage test.
- Biyometrik uygulama kilidi ayrı UI erişim kapısı; DB key biometric-enrollment-bound yapılmaz, parmak izi değişiminde key kaybı riski azaltılır. Bu tasarım donanım biyometrisiyle kriptografik DB unlock iddiası değildir; OS cihaz şifrelemesi ve app sandbox'a dayanır. DB key yalnız gerekli foreground session'da alınır, app lock olduğunda handle kapat/temizle, in-memory cache temizle; JS memory sıfırlama garantisi yok. Native capture queue/HMAC ayrı key ve storage, ledger access yok. İlk cihaz unlock öncesi key erişimi yoksa plaintext fallback yok. Headless DB unlock varsayılan kapalı; ADR-0014 spike güvenlik şartları.
- Kullanıcı opt-in lock: Expo Local Authentication, güçlü biyometri destekleniyorsa; OS device credential fallback (native API/SDK uyum doğrula), ayrı uygulama PIN ve recovery server yok. İlk açılış, background'dan dönüşte varsayılan hemen yeniden auth; OS auth prompt lifecycle re-entry engelle. Lock screen ve deep link, notification, widget, export/restore route, app switcher cover; auth başarısız/cancel -> locked; cihaz credential da yoksa lock enable etme. OS screenshot protection imkanları platforma göre; garanti değil. Kilit kapatma ve hassas export/restore için fresh auth (lock etkin ise). Widget visible consent kararı: app lock etkinleştirilince tüm visible consent reset ve mask; lock açıkken widget finansal değerler maskeli kalır, quick add güvenli route. Lock kaldırılırsa yeniden ayrı opt-in. OS cache anlık silinmez. Global hide tüm widget'ları override eder.
- Hiçbir raw banka/SMS/OTP/full PAN/IBAN, capture queue veya device key backup/sync/log'a girmez. ADR-0014 structured queue 7 gün/500 olay, pending 30 gün; replay ledger linki korunur, expiry ve purge. Capture secret rotation/restore: auto kapalı, account mapping yeniden onay, queue purge. Minimum pseudonymous diagnostics; crash/analytics üçüncü tarafı varsayılan yok.

## 2. Portable encrypted backup (ilk öncelik)
- Kullanıcı açık action ile logical snapshot: tek read transaction consistent ledger, categories, tags, templates, plans, allocations, budgets, goals, gerekli settings ve rate snapshot. Schema/versioned canonical JSON; minor integer string. Raw content, transient candidates/queue, rules ve device-specific capture mappings/keys, auth tokens, widget snapshot ve caches dışarıda. Journal'ın source/idempotency ve ilişkileri korunur; capture automation restore sonrası review-first. Local account IDs korunur. CSV/JSON export ayrı, backup yerine geçmez.
- .sumlune-backup version 1 envelope: magic, formatVersion, bounded KDF parameters, random salt >=16 bytes, AES-256-GCM random 12-byte nonce per export, 16-byte tag, ciphertext. Header canonical authenticated AAD; encrypted payload metadata (schemaVersion, createdAt, datasetId, records). PBKDF2-HMAC-SHA256 600000 iterations v1 başlangıç tercihi (doğrulama şartlı), minimum 12 karakter passphrase ve güçlü uzun passphrase önerisi, platform native KDF performansı ve güncel tavsiye DEV-00 gate. Parola normalize kuralı sabit UTF-8 NFC; trim yok. Crypto primitives platform güvenilir kütüphanesi (expo-crypto AES-GCM destekli SDK veya native AES-GCM ve native KDF); custom crypto algoritması yok, known-answer/cross-platform test. Unsupported format/KDF, aşırı iteration veya boyut reddedilir; başlangıç max encrypted file 20 MiB, records ve JSON nesting bounded; kapasite aşarsa veri kesilmez, kullanıcıya hata. Parola/key backend'e gitmez, kayıp parola kurtarılamaz. Şifreli dosya dışında plaintext geçici dosya yok. OS document picker/share sheet ile yerel veya kullanıcı seçtiği Drive/iCloud/dosya sağlayıcısı. Şifreli dosya manuel dışarı kopyalandığında uygulama onun silinmesini garanti edemez. Otomatik server yok.
- Restore: dosya boyut ve envelope doğrula -> KDF/authenticated decrypt -> versioned schema + safe integer/FK/journal balance/alloc capacity/idempotency validate -> preview (date, counts, currency, data impact) -> fresh auth ve explicit replace -> staging encrypted SQLite yeni key -> migrate/integrity_check/foreign_key_check/aggregate checks -> crash-safe swap. Mevcut DB ve key başarılı açılış doğrulanana kadar şifreli rollback olarak tutulur. Crash recovery state ve cleanup test; hata, yanlış parola, bozuk dosya veya newer unsupported version mevcut DB'yi bozmaz. Merge ilk backup restore kapsamı değil; explicit replace, önce mevcut şifreli backup oluşturma seçeneği. Restore sonrası cache/snapshot/queue/notification rebuild, cloud sync pause, capture review-first; eski key'leri ancak başarılı swap sonrası güvenli kaldır. Silme ve yeniden kurulum için açık onay. 
- CSV/JSON export açık metin uyarısı + kullanıcı seçtiği hedef; global hide görsel gizlilik, export ayrı explicit consent. JSON version, integer-string, CSV amount major decimal string/currency/date, CSV formula injection escape text columns (spreadsheet-safe), UTF-8. Export finansal kaydı kapsar, secrets/raw yok. Plaintext temp kaçınılmaz ise app-private, no backup, share completion/TTL cleanup, kullanıcı hedef kopyası kontrolümüz dışı. JSON/CSV genel import onaylı değil.
- Backup hatırlatma yerel UI: son başarılı backup tarihi, isteğe bağlı periyodik reminder; sessiz yedek upload yok. Şifreli local backup/restore cross-platform device test zorunlu.

## 3. Doğrulama ve maliyet
Kaynaklar: https://docs.expo.dev/versions/latest/sdk/securestore/ ; https://docs.expo.dev/versions/latest/sdk/crypto/ ; https://docs.expo.dev/versions/latest/sdk/local-authentication/ . Expo SecureStore requireAuthentication biometric enrollment değişiminde invalidation riski taşır; bu nedenle UI gate ayrımı. AES-GCM API mevcut SDK'larda dokümante, seçilecek SDK/KDF uyumu ve cihaz performansı doğrulanacak. Test: lost key, reinstall, biometric enrollment change/cancel, app-switcher, deep link bypass, masked widget race, queue key unavailable, SQLCipher ciphertext/WAL, wrong password/tag/tamper, malicious oversized file, backup Android→iOS→Android, crash at restore swap, export leakage, missing FK/imbalanced journal, future schema. Uygulama kodu/cihaz testleri yok. Cloud ayrı [SYNC](SYNC.md). Crypto/policy teknik doğrulama şartı; ücretli servis gerekli değil.

## 4. Kesin teknik seçimler (ADR-0016)
- Local-first security başlangıçtan uygulanır. Cihaz key erişimi ve UI auth ayrıdır; lock açıkken foreground session dışında ledger erişimi yok. Lock aktifken widget görünür tutar izni verilemez; global hide her durumda öncelikli. App lock kapalıyken widget explicit opt-in mümkün. App background cover ve session invalidation; native auth prompt dönüşü kendi doğrulamasını tetikleyen sonsuz döngüye yol açmaz. Auth yapılandırması değişirse locked state ve explicit OS credential fallback; kurtarma için DB silme yok.
- Rastgele DB key, ayrı capture queue AES key ve HMAC key; platform secure storage, no backup. Mevcut DB/key uyumsuzluğunda recovery-only. Restore sırasında şifreli staging DB, key ve swap state ayrı; crash sonrası ya eski ya doğrulanmış yeni DB açılır. Backup version/AEAD/KDF sözleşmesi bağlayıcı; crypto API ve parametre performansı/güncel güvenlik uygunluğu teknik gate. KDF düşürülmez veya plaintext fallback uygulanmaz. Envelope boyut/KDF üst sınırı doğrulamadan pahalı derivation başlatma. Key/nonce tekrar kullanımı yok. Parola kullanıcıya ait, kayıp parola için backdoor yok.
- Backup allowlist versioned ve kapsam testli; cihaz lock, privacy consent, capture mapping/rule, queue, cloud token, sync state ve widget cache dışarıda. Restore varsayılan maskeli, mevcut cihazın lock tercihi korunur, capture auto kapalı ve cloud sync pause. Journal idempotency ve allocation/reversal ilişkileri korunur. Restore yalnız explicit replace; merge yok. Dosya dışa aktarımında başarı ancak dosya yazımı doğrulanınca. Son backup tarihi gerçek başarıya göre; manuel seçilen dış hedefte dosya silinirse uygulama garanti vermez.
- CSV/JSON export açık metindir; ayrı explicit confirmation, auth gerekiyorsa fresh auth; schemaVersion ve minor integer string JSON, okunabilir major decimal ve currency CSV. Formula injection korunur, hiçbir şifre/ham banka içeriği yok. Android/iOS cross-platform backup fixture, yanlış parola/bozuk dosya ve crash-safe swap zorunlu release gate. 20 MiB başlangıç limiti aşılırsa hata, hiçbir veri sessizce atılmaz. Hiçbir crypto veya cihaz testi henüz yapılmadı.
