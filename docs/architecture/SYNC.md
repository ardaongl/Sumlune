# Local-first & Optional Cloud Sync — PLAN-07 / Accepted (ADR-0016; provider koşullu)

ADR-0003 Accepted: offline ve üyelik olmadan temel kullanım; opsiyonel cloud backup ve cihazlar arası sync kapsamda. Aşamalı teslimat ve snapshot protokolü ADR-0016 ile Accepted; provider, kota ve crypto doğrulaması şartlı. SQLite her cihazda tek finansal veri kaynağı; network/auth/cloud down core'u durdurmaz. Ürün kapsamı silinmez, teslim sırası ayrılır.

## 1. Üç basamak
1. Local portable encrypted backup/restore (SECURITY.md): ilk kullanılabilir ürün, hesap yok, kullanıcı OS file provider seçebilir. Drive/iCloud elle saklanan dosya bulut dosya kopyasıdır, uygulama içi sync değildir.
2. Opt-in uygulama içi cloud backup: aynı encrypted snapshot, kullanıcı hesabı yalnız bu özellik için. Supabase Auth + private Storage aday, RLS ownership, TLS, minimum metadata, no privileged service role in client. Hesap açma, yükle/indir/sil, son backup ve quota/error UI. Kullanıcı şifresi/device key provider'a gitmez; yalnız ciphertext. Manuel upload/download önce. Free tier kota ve pause şartı, auth delivery ve storage limitleri doğrulanacak; fiyat ve süreklilik garanti değil. Ek ücret otomatik kabul edilmez. Yerel kopya korunur, kullanıcı her an local export yapabilir.
3. Opsiyonel çok cihazlı sync: önce düşük maliyetli encrypted whole-dataset snapshot sync; optimistic compare-and-swap (CAS) ve açık conflict review. Gerçek zamanlı row-level merge, realtime subscription, event store, CRDT, ayrı microservice başlangıçta yok. Sync ayrı faz, core release'e blocker değil; kullanıcı kabulü ve doğrulama olmadan tamamlandı sayılmaz.

## 2. Snapshot sync — önerilen sözleşme
- Aynı datasetId UUID, deviceId random, local revision artan integer, remote revision/opaque version token, lastSyncedLocalRevision ve baseRemoteVersion. Local revision finansal/plan/settings syncable mutation ile aynı SQLite transaction'da artar; transient UI/capture queue ve widget değişikliği sync dışı. Tek metadata row, global dirty state; önceki revision'a dayanma; schema/crypto version. Encrypted full logical dataset (SECURITY allowlist); cihaz anahtarı veya raw bank message yok. Password/recovery secret kullanıcı diğer cihazda girer; server password recovery ciphertext'i çözmez. Sync secret CSPRNG data encryption key veya passphrase-derived key ayrı native secure store; ilk basit çözüm her snapshot ayrı salt/nonce ile aynı kullanıcı passphrase'den derivation, yalnız unlocked foreground session içinde geçici key cache; KDF/latency spike. Ayrı cihazda parolayla doğrulama; encryption at source before upload, decrypt on device. Metadata server sees: user/dataset IDs, revision, timestamps, size, encrypted blob path; finansal içerik görmez. RLS erişim kontrolü E2EE yerine geçmez.
- Supabase aday minimal remote metadata row (owner, datasetId, headRevision, blobPath, updatedAt) ve private immutable blob. Upload new revision candidate to owner-scoped path -> authenticated conditional head CAS (expected head) atomic SQL transaction/RPC -> success update local synced revision; upload başarısızsa local dirty kalır; CAS fail orphan cleanup (ownership, current head korunur), retry idempotent operation id. Server revision başına ciphertext authentication/AAD bağlamı owner-independent datasetId + intended revision + format; plaintext olmadan version check. RLS hem metadata hem object; iki farklı kullanıcı izolasyon test; client secret yok. Read head ve immutable object hash/AEAD validate. Eski/rollback/replay ve revision mismatch güvenli hata; server malicious rollback tamamen önlenemez, local last-seen head kontrolü. Retention current + previous successful version, quota aşarsa current silinmeden uyarı. Cloud backup geçmişi ayrı explicit snapshot object, retention/size sınırı.
- Sync foreground app open/explicit sync ve değişiklik sonrası coalesced, yalnız auth+unlocked+network; backoff, no background polling/realtime; initial manual only güvenlik spike. Network/auth/limit fail local kullanım devam. Yeni cihaz boşsa explicit dataset download/restore; mevcut local kayıt varsa overwrite prompt ve backup.
- Conflict: local clean + remote advanced -> validate staged encrypted restore, local changes still absent under lock, atomic replace; local dirty + remote unchanged -> CAS upload; both changed -> **Blocked conflict**, hiçbir taraf otomatik silinmez/overwrite/merge edilmez. İki versiyon korunur; kullanıcı local/remote özetini (decrypt cihazda) görür, iki şifreli backup export edebilir. Explicit keep local veya use remote; diğer tarafı kaybetmeye karşı ayrı encrypted copy zorunlu, latest head recheck/CAS; sonra sync resume. Otomatik satır birleşimi yok, tek aktif düzenleme cihazı önerilir; eşzamanlı değişiklikleri elle uzlaştırma gerekir. Conflict çözümü finansal journal'ı tek aggregate olarak korur. Tombstones/change_log/sync_outbox başlangıçta gerekli değil, full snapshot deletion'ı taşır; ileride gerçek merge gerekiyorsa ayrı ADR. User onayı olmadan LWW yok.
- Cloud disconnect local veri kalır; local secret/token clear, auto upload stop; remote delete ayrı explicit auth/confirm, local encrypted backup önerisi. Account deletion metadata + objects + orphan cleanup; provider backups/retention ve deletion time sınırları açıklanır. No raw capture/queue/rules/device mapping sync; restore review-first. Syncable dataset field allowlist ile backup aynı; cihaz ayarları/biometric/privacy ayrı, restore default masked.

## 3. Maliyet ve güvenlik kapısı
Supabase aday: private Storage RLS ve owner-scoped metadata/CAS; auth/storage free tier kapasitesi mevcut fiyat/kota/uyku koşulları ile DEV-00 ve cloud fazında tekrar doğrulanacak. Kaynaklar: https://supabase.com/docs/guides/storage/security/access-control ; https://supabase.com/docs/guides/storage/uploads/file-limits ; https://supabase.com/pricing . Sunucu tarafı encryption key yok, yalnız client-side AEAD; platform access control tek başına E2EE değil. No paid API, no mandatory backend for local. Cloud runtime free-tier koşullu, gelecekte ücret/limit mümkün; alternatif encrypted manual backup sürekli kullanılabilir. Auth email teslimi/rate limit/hesap silme test. İlk cloud limit 20 MiB per snapshot, quota gate, no automatic paid upgrade. 
Test: RLS cross-user, ciphertext only, same/changed password and recovery, interrupted upload/CAS race/duplicate retry, orphan cleanup, offline edits, stale remote, clean pull vs dirty conflict, both backups preserved, local restore during sync, newer schema, corrupted payload, device loss, disconnect/delete, quota/full storage, no silent overwrite. Teknik test, Supabase projesi, kod, deployment yok. PLAN-07 onaylandı; uygulama ve teknik doğrulama ayrı faz.

## 4. Kesin teknik seçimler (ADR-0016)
- C: local encrypted backup/restore ilk kullanılabilir sürümde zorunlu; in-app cloud backup ve multi-device sync ayrı ardışık opsiyonel fazlar. İkisi de kapsamda kalır, local release blocker değildir. Supabase yalnız aday; ücretsiz kota, storage policy, auth/email ve RLS/CAS testlerinden önce proje açma/deploy veya ücretli plan yok. Local file provider dosya kopyası sync olarak pazarlanmaz.
- İlk cloud backup manuel upload/download; sync ilk sürüm explicit sync, sonra yalnız foreground/unlocked opt-in coalesced sync güvenli doğrulanırsa. Tek dataset aktif, 20 MiB encrypted limit, current + previous successful head, manuel backup ayrı açık kota; no realtime, no background polling, no per-row merge/outbox. CAS expected opaque head + idempotent operation id; head pointer yalnız doğrulanmış owner blob'a geçer. Blob retention/orphan cleanup current/previous head'i silmez; CAS race test. Remote metadata içerik sızıntısı ayrı açıklanır.
- Snapshot AES-GCM ve passphrase-derived key SECURITY sözleşmesiyle aynı primitive; sync metadata (datasetId, revision, format) authenticated AAD. Ayrı cihaz parola ile açar; parola/key server'a gönderilmez. KDF cache yalnız unlocked session; lock/exit'te referans temizlenir. Parola değişimi ilk sürümde otomatik rotation değil: şifreli backup oluştur, sync durdur, kullanıcı onayıyla yeni encrypted dataset oluştur; eski cloud kopya açık deletion kararıyla. Hesap parola reseti şifreli veriyi çözmez.
- Conflict UI: local/remote revision ve özet, iki şifreli kopyayı koru; kullanıcı açık 'yerel sürümü tut' veya 'bulut sürümünü kullan' seçer. Varsayılan hiçbir seçim; merge yok. CAS/revision recheck sonrasında işlem; bu arada yeni edit olduysa conflict yeniden. Losing version encrypted backup başarıyla yazılmadan discard yok. Cloud disconnect veriyi silmez; delete/account delete ayrı fresh auth ve confirm. Yerel restore sync pause ve explicit reattach/rebase. Device-specific settings dışarıda. Free tier aşılırsa sync durur/uyarır, local işlevler devam; otomatik ücret yok. Uygulama, cloud proje ve test yok.
