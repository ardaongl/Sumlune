# ADR-0003 — Local-first + opsiyonel bulut

**Durum:** Accepted  
**Tarih:** 2026-11-26

## Bağlam ve karar
İnternetsiz/üyeliksiz kullanım; isteğe bağlı bulut backup ve cihazlar arası sync.

## Alternatifler
Tamamen local, cloud-first.

## Sonuçlar ve sınırlar
SQLite/encryption/Supabase/sync protokolü ayrı teknik öneri. Bulut implementation sonraki aşama önerisi.
