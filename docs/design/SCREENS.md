# Ekran yapısı — Proposed

| Alt navigasyon | İçerik |
|---|---|
| Özet | Bakiye, güvenle harcanabilir, dönem grafiği, yaklaşan ödeme, son işlemler |
| İşlemler | Gelir/gider/transfer, arama, filtre, detay |
| Ekle | Ortada aksiyon; bottom sheet, gider/gelir/transfer, şablon |
| Planlama | Abonelik/fatura/kira/taksit/borç/alacak, takvim |
| Analiz | Bütçe, birikim, geçmiş karşılaştırma, tahmin, ısı haritası |

Hesaplar bakiye alanından; ayarlar ve inbox üst navigasyondan. Onboarding, hesap/kategori/tag, işlem detay, plan detay, capture inbox/rules, widget, izin, güvenlik, backup/sync ek rotalar. Kişiselleştirilebilir dashboard öneri, kapsam onayı yok.

Özet hiyerarşisi: büyük bakiye, güvenle harcanabilir, harcama aktivitesi, yaklaşan ödemeler. İşlem ekranı tutar/kategori/hesap/tarih/açıklama/etiket ve şablon. Empty/error/loading/permission denied/locked, TR/EN ve tema kabul kriterleri sonra. Nihai Figma/gerçek UI yok.
