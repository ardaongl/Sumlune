## UI quality contract
- Primary action per screen, large title only root tabs, compact detail header, 20dp margin, 52 row min/48 touch; no excessive cards. Group related rows, semantic typography and color. Bottom tab stays safe area; keyboard and sheets do not obscure save. System dialogs permissions/auth. Native back handles sheet before tab stack. No forced onboarding permissions.
- Overview: one primary balance, secondary safe-to-spend section with assumptions; monthly spending line/progress only data-backed, no invented charts. Rows show amount and signed direction; global privacy replaces values and related accessibility labels. No custom dashboard configuration.
- Add form: amount first, use currency exponent, input string, appropriate keyboard; optional custom keypad only if accessible and improves speed; no custom keypad required. Default last successful compatible account, category explicit; date today, optional details collapsed; account missing create path. Target 3–5 sec common expense measured later. No automatic save from widget/template.
- Light/dark/system, TR/EN localized strings and currency/date format, long strings and large text (200% test target), logical layout, screen-reader focus/order, reduce motion; icons secondary to text. Contrast WCAG AA target (4.5:1 normal text, 3:1 large/meaningful controls); adapt token usage after verification. Native font fallback if Inter licensing/bundle issue. iOS system font not redistributed.
- Navigation from deep links is allowlisted and lock-gated; no account number/amount in URI. App switcher privacy, restore safe state. No fake features, test data only dev. Success after database commit; read models shared; no analytics or widget direct writes. Device tests and acceptance checklists PLAN-09. Screen visual hierarchy approval still pending.
