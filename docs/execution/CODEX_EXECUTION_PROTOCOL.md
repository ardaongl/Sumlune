## Durum ve geçiş

Phase blueprint statik, PROGRESS durum/evidence ve yüzde tek kaynak; CURRENT_STATE üst seviye, BACKLOG planlama, SESSION_HANDOFF operasyon özeti. Task gate: actual tests + relevant Q subchecks + verified code SHA + no P0/P1. Failed/not-run/blocked mandatory gate geçmez; P2 ölçülür ve review. Q groups partial evidence ayrı. Son code checkpoint sonrası docs-only evidence commit olabilir. Kod değişimi etkilenen kanıtları invalidates. Scope/ADR değişikliği açık onay. Uygulama başlatma ve sonraki faz yetkisi ayrı.
