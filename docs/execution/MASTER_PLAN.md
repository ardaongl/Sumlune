# Sumlune Master Implementation Plan — ADR-0019
**Planlama tamamlandı; geliştirme yetkisi verilmedi.** 13 faz, 64 sıralı görev. 00–09 local Android-first; 10 gated SMS; 11–12 optional cloud. Android-first teslim sırası iOS kapsamını silmez. iOS lane evidence her fazda ayrı, unavailable ise iOS release blocked; core Android ilerlemesi için explicit platform separation. 07/08/09 bank/renderer blocker kapsam değişikliği değildir; local checkpoint narrower ise owner onayı ve missing feature açık, full acceptance yok. Faz sırası ve reset grupları maliyet odaklı devredilmiş planlama kararı; gerçek Codex kapasitesi bilinmiyor.

## Öncelik
Reset 1: 00–03, exact local ledger. Reset 2: 04–05 plans/analytics. Reset 3: 06–07 backup first and bank push. Reset 4: 08–09 widgets/hardening. Security baseline baştan; gerçek kişisel veri ancak 06 recovery gate sonrası. Riskli spike'lar 00'da. SMS 10 sadece izin ve kapasite; cloud 11,12 ayrı, zorunlu local release değil. Tahmin, garanti değil. Reset dolmadan checkpoint, sonraki oturum aynı active task'tan. Dört resetin içine sığmazsa kapsam silmek yerine güvenli ara teslim ve yeni kullanıcı kararı.
## Kaynak otoritesi
SCOPE/ADR accepted iş kuralları; QUALITY_MATRIX 38 grup; UX-01..25 ekran sözleşmesi; SCOPE_TRACEABILITY eşleme. PROGRESS tek mutable implementation state. MASTER_PLAN statik, SESSION_HANDOFF son operasyon notu, CURRENT_STATE üst düzey phase/authorization; BACKLOG planlama durumudur. Duplicated independent percent yok. Blueprint dosyaları statik; task durumu oraya yazılmaz.
